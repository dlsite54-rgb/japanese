2. 자리 단위 (十, 百, 千, 万)

  • 十 (대자: 拾) = 10 (じゅう / 쥬우) — 예: 二十五 = 25
  • 百 (대자: 佰) = 100 (ひゃく / 햐쿠) — 예: 三百 = 300
  • 千 (대자: 仟) = 1,000 (せん / 센) — 예: 四千 = 4000
  • 万 (대자: 萬) = 10,000 (まん / 만)

3. 일본어 사칙연산 표현

  • 足す (たす / 타스) = + (더하기 / Plus)
  • 引く (ひく / 히쿠) = − (빼기 / Minus)
  • 掛ける (かける / 카케루) = × (곱하기 / Multiply)
  • 割る (わる / 와루) = ÷ (나누기 / Divide)
